Tips:
- Project card images look best at roughly **16:10 landscape** (e.g. 1280×800).
  iPhone screenshots also work — they're cropped from the top automatically.
- The `hero.png` should be a **portrait iPhone screenshot** (9:19-ish).
- `.png` is expected; if you have `.jpg`, either rename them or update the
  matching `<img src>` in `index.html`.
- Until an image exists, a colored placeholder with the app's initial is shown.
